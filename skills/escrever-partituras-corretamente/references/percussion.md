# Notação de bateria e percussão

## Princípios

- Definir previamente a convenção de pauta e incluir legenda quando ela não for padrão para o intérprete.
- Preservar a identidade do instrumento em quatro dimensões: som/MIDI, posição na pauta, notehead e técnica.
- Usar voz superior, em geral com stems para cima, para pratos/chimbais; usar voz inferior, em geral com stems para baixo, para bumbo e pedal. Adaptar quando a textura exigir.
- Não fundir eventos simultâneos de peças diferentes em um único som simbólico.
- Representar ghost notes, flam, drag, roll, choke, bell, edge, rimshot e cross-stick somente quando presentes ou editorialmente solicitados.

## Mapa General MIDI de referência

Este mapa identifica som MIDI, não determina sozinho posição ou notehead:

| Nota MIDI | Som |
|---:|---|
| 35/36 | Acoustic Bass Drum / Bass Drum 1 |
| 37 | Side Stick |
| 38/40 | Acoustic / Electric Snare |
| 41/43/45/47/48/50 | Toms |
| 42 | Closed Hi-Hat |
| 44 | Pedal Hi-Hat |
| 46 | Open Hi-Hat |
| 49/57 | Crash Cymbal 1/2 |
| 51/59 | Ride Cymbal 1/2 |
| 53 | Ride Bell |
| 52/55 | Chinese / Splash Cymbal |

## Verificações

- Chimbal aberto precisa de símbolo/técnica de fechamento quando o áudio a contém.
- Ride bell e ride bow não são intercambiáveis.
- Crash sustentado não deve virar sequência de ataques para preencher duração.
- Roll deve indicar subdivisão, duração e número de ataques quando necessário.
- Flam e drag devem ser ornamentos executáveis, não notas principais desalinhadas.
- Bumbo duplo deve preservar ataques reais; não duplicar por vazamento de baixa frequência.
- Pausas de cada voz devem mostrar o groove sem poluir a página.
- Em partitura completa, conferir nomes e abreviações de cada instrumento de percussão.
